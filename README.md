# ยกมือตอบ

เกมทำข้อสอบด้วยกล้อง สำหรับใช้ในห้องเรียน มีสี่เกม ยกมือตอบ จับคู่ ยืนเลือกช่อง และด่านนั่งยืน

## ไฟล์ในโฟลเดอร์นี้

| ไฟล์ | หน้าที่ | ต้องแก้ไหม |
|---|---|---|
| `index.html` | ตัวเว็บทั้งหมด | ไม่ต้อง |
| `config.js` | ใส่ลิงก์ Apps Script ที่เก็บข้อสอบ | แก้บรรทัดเดียว |
| `README.md` | ไฟล์นี้ | ไม่ต้อง |

## ลิงก์ของเว็บ

หลังเปิด GitHub Pages แล้ว ลิงก์จะเป็นแบบนี้

```
https://ชื่อผู้ใช้.github.io/ชื่อคลัง/
```

ส่งลิงก์นี้ให้นักเรียนได้เลย ไม่ต้องต่อท้ายอะไร

## เวลาจะแก้ข้อสอบ

ไม่ต้องแตะไฟล์ในนี้ ให้เข้าเว็บแล้วใช้เมนูสร้างแบบฝึก กดบันทึกขึ้นออนไลน์ ข้อสอบจะไปเก็บที่กูเกิลชีต นักเรียนกดโหลดข้อสอบจากครูใหม่ก็เห็นทันที

## เวลาจะอัปเดตตัวเว็บ

ถ้าได้ไฟล์ `index.html` เวอร์ชันใหม่มา ให้กด Add file แล้ว Upload files วางทับของเดิม รอประมาณหนึ่งนาทีเว็บจะอัปเดตเอง
